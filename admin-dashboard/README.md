# لوحة إدارة البرازيلي المستقلة

هذه الواجهة منفصلة عن واجهة اللاعبين، لكنها تستخدم Backend/API وقاعدة بيانات التطبيق الأساسي كمصدر واحد للمزامنة. تسجيل دخول المشرفين يتطلب البريد وكلمة المرور ثم رمز OTP يُرسل عبر SMTP.

## التشغيل

من جذر المشروع:

```bash
pnpm exec vite --config admin-dashboard/vite.config.ts
```

لتوجيه الواجهة إلى الموقع الأساسي عند تشغيلها على نطاق مستقل:

```bash
VITE_API_ORIGIN=https://elbarzily-jbwnvolp.manus.space pnpm exec vite --config admin-dashboard/vite.config.ts
```

يجب ضبط `ADMIN_DASHBOARD_ORIGIN` في بيئة خادم التطبيق الأساسي إلى أصل لوحة الإدارة إذا نُشرت على نطاق مستقل حتى يسمح CORS بالطلبات مع جلسة HttpOnly. أثناء التطوير يُسمح تلقائياً بـ `http://localhost:3200`.

بعد النشر العام تُفتح اللوحة من: `https://elbarzily-jbwnvolp.manus.space/admin-dashboard/`. هذه واجهة مستقلة عن تطبيق اللاعبين لكنها منشورة تحت مسار منفصل، وتستخدم نفس Backend/API وقاعدة البيانات؛ لا تستخدم مسار `/admin` القديم.

اللوحة تشمل: نظرة تشغيلية، إدارة المشرفين والصلاحيات، تعطيل/إزالة المشرفين مع حماية المدير العام، سجل نشاط إداري، محادثات خاصة ومجموعات، ورسائل نصية/وسائط/صوتية عبر API المشترك. يتم تحديث البيانات تلقائياً كل عدة ثوانٍ لتوفير مزامنة شبه لحظية دون فتح منفذ قاعدة بيانات للمتصفح.
